# Biomed — Biotecnología y medicina

Sitio académico estático en español sobre biotecnología médica.

## Páginas
- Inicio: `index.html`
- Nosotros: `nosotros.html`
- Marco teórico: `marco-teorico.html`
- Resultados: `resultados.html`
- Impactos: `impactos.html`
- Referencias: `referencias.html`

Todas las páginas son independientes y comparten navegación, estilos y JavaScript. Las rutas relativas funcionan en GitHub Pages bajo `/biotecnologia/`.

## Investigación
Revisión documental narrativa internacional de 2020–2024. Incluye antecedentes bibliográficos, indicadores de la OMS y el caso de Casgevy en Estados Unidos y Reino Unido. Fuentes institucionales: OMS (2021, 2024), FDA (2023) y MHRA (2023). El antecedente de 2008 se identifica como histórico. No presenta mediciones ni resultados clínicos propios.

## Dashboard de Resultados
Tres vistas accesibles por ratón, toque y teclado:
- Contexto mundial: 20 millones de casos nuevos y 9,7 millones de muertes por cáncer en 2022.
- Cobertura sanitaria: 39 % de 115 países participantes; encuesta 2020–2021.
- Caso Casgevy: 29 de 31 pacientes evaluables alcanzaron el desenlace, de 44 tratados; FDA (2023).

Cada vista incluye fuente, período, unidad y límites de interpretación. Los gráficos mantienen separados los indicadores poblacionales y el ensayo clínico. Las tres vistas permanecen disponibles sin JavaScript.

## Diseño y accesibilidad
Diseño oscuro con acentos cian y violeta, imágenes conceptuales responsivas, partículas decorativas con movimiento reducido, menú móvil, foco visible y acordeones nativos. Space Grotesk e Inter desde Google Fonts con alternativas locales. Las ilustraciones no representan instalaciones reales ni evidencia experimental.

## Ejecución
Sin compilación ni dependencias de ejecución. Abrir `index.html` o servir la carpeta mediante un servidor estático. GitHub Pages publica la rama `main` desde la raíz.
