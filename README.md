# Chess AI ♞

Juego de ajedrez web responsive para practicar contra una IA local.

## Funciones
- Reglas legales completas mediante chess.js
- 5 niveles de dificultad
- Blancas, negras o color aleatorio
- Pistas, deshacer, girar tablero y rendirse
- Historial de movimientos
- Interfaz adaptable a móvil y escritorio
- Entrenador con comentarios contextuales

Abre `index.html` o publica el repositorio con GitHub Pages.

> Primera versión: la IA integrada usa evaluación local ligera. La arquitectura queda lista para incorporar Stockfish/WebAssembly y análisis profundo en una siguiente fase.
